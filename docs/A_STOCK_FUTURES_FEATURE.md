# A股和期货支持功能说明

## 功能概述

系统现已支持识别和获取A股、期货的实时价格数据，与美股一起统一管理。

## 支持的标的类型

### 1. 美股 (us_stock)
- **代码格式**：1-5个字母，如 AAPL、MSFT、SLV
- **数据源**：Alpha Vantage API
- **市场**：NYSE、NASDAQ等

### 2. A股 (a_stock)
- **代码格式**：6位数字
  - 上交所（SSE）：以6开头，如 600519（贵州茅台）
  - 深交所（SZSE）：以0或3开头，如 000001（平安银行）、300015（爱尔眼科）
- **数据源**：akshare库（免费）
- **市场**：SSE（上交所）、SZSE（深交所）

### 3. 期货 (futures)
- **代码格式**：2-4个字母，如 AG（白银）、AU（黄金）、CU（铜）
- **数据源**：akshare库（免费）
- **交易所**：
  - SHFE（上海期货交易所）
  - DCE（大连商品交易所）
  - CZCE（郑州商品交易所）
  - CFFEX（中国金融期货交易所）

## 安装依赖

要使用A股和期货功能，需要安装akshare库：

```bash
pip install akshare>=1.12.0
```

或者安装所有依赖：

```bash
pip install -r requirements.txt
```

## 使用方法

### 1. 自动识别

系统会自动从关键词和文章中识别A股和期货代码：

- **A股识别**：系统会识别6位数字代码，并自动判断是上交所还是深交所
- **期货识别**：系统会识别常见的期货代码（如AG、AU等），并标注交易所

### 2. 手动识别

在Web界面的"相关股票"标签页，点击"识别股票"按钮，系统会：
- 从关键词中识别美股、A股和期货
- 从高置信度文章中识别相关标的

### 3. 查看和筛选

在"相关股票"标签页：
- 可以按类型筛选：全部、美股、A股、期货
- 每只标的会显示类型标签（美股/A股/期货）
- 显示市场/交易所信息

### 4. 价格更新

- 系统每30分钟自动更新所有活跃标的的价格
- 也可以手动点击"更新价格"按钮
- 美股使用Alpha Vantage API
- A股和期货使用akshare库

## API接口

### 获取识别的标的列表
```
GET /api/stocks/identified?stock_type=a_stock&limit=50
```

参数：
- `stock_type`: 可选，us_stock/a_stock/futures
- `active`: 可选，true/false
- `limit`: 可选，数量限制

### 获取标的实时价格
```
GET /api/stocks/<symbol>/price?type=a_stock
```

参数：
- `type`: 可选，us_stock/a_stock/futures（如果不提供，系统会自动检测）

## 数据源说明

### Alpha Vantage（美股）
- 需要配置 `ALPHA_VANTAGE_API_KEY`
- 免费版有调用频率限制（每分钟5次，每天500次）
- 获取地址：https://www.alphavantage.co/support/#api-key

### akshare（A股和期货）
- 免费开源库，无需API密钥
- 数据来源于各大交易所和财经网站
- 安装：`pip install akshare`
- 文档：https://akshare.readthedocs.io/

## 注意事项

1. **A股代码格式**：
   - 必须是6位数字
   - 上交所：6开头
   - 深交所：0或3开头

2. **期货代码**：
   - 系统会自动识别常见期货代码
   - 目前主要支持国内期货交易所的品种

3. **数据更新频率**：
   - 美股：受Alpha Vantage API限制
   - A股和期货：akshare数据更新较快，但建议不要过于频繁调用

4. **价格单位**：
   - 美股：美元（$）
   - A股：人民币（元）
   - 期货：人民币（元/手）
